# 原石航路

まだ知られていない物語に出会うための、小説の投稿サイト。

本番: https://gensekikoro.com

書く人には執筆と資料整理の道具を、読む人には埋もれた作品を掘り出す道を用意する。
その 2 つを 1 つのサイトに収めているのが、この作りの要点。

---

## つくり

| | |
|---|---|
| 骨組み | Next.js 14（App Router） |
| データ | Supabase（Postgres + 認証 + 画像置き場） |
| 置き場所 | Vercel |
| 住所 | Cloudflare で取得、Vercel に接続 |

**保存先はすべて Supabase。** 端末の中には持たない。

## 2 つの向き

同じサイトが、人によって違う顔を見せる。

```
作家向け（home_mode = write）
  ホーム    自分の本棚・執筆室・書きかけの話
  行き先    ホーム / 作品を書く / 作品を探す / ランキング / コミュニティー / コンテスト

読書向け（home_mode = read）
  ホーム    新着・おすすめ・ランキング・お知らせ
  行き先    ホーム / 作品を探す / ランキング / おすすめ / コミュニティー
```

**入っていない人には読書向けを出す。** 執筆向けは、入っていないと空の枠が多く、
何ができる場所か伝わらないため。その向きはクッキーに覚える。

ヘッダーのベルの左に切り替えがある。押すとその場で入れ替わり、頁を読み込み直す。
ホームの中身も行き先の並びも変わるので、作り直しだけでは古い部品が残る。

## 書く側

| 機能 | 中身 |
|------|------|
| 執筆 | 縦書き・自動保存・文字数・集中モード・版の記録 |
| 話の管理 | 並べ替え・章・予約投稿・一括の公開 |
| 資料 | 人物・場所・組織・用語・アイテム・事件・メモ・関係図・年表・プロット |
| 本文との紐づけ | 本文から資料候補を拾う／蛍光ペンで手動で足す／間違いを消す |
| 推敲 | 表記ゆれ・重複・一括修正 |
| 取り込み | TXT / MD / PDF |
| 書き出し | TXT / PDF / JSON |
| 挿絵 | 話ごとに 1 枚。読む画面で本文の中に出る |

### 本文の記法

ルビと傍点だけは本文に埋め込む。**「本文は素のテキスト」という方針の唯一の例外。**
どの文字にどう読ませるかは文字の並びと不可分で、位置を別の表に持つと
本文を 1 文字直すたびに全部ずれるため。

```
｜原石《げんせき》   親文字を指定する
原石《げんせき》     直前の漢字の連なりに振る
《《ここ》》          傍点
```

記法は日本語の投稿サイトで広く使われているものに合わせている。
独自記法にすると、書き手が他所から持ってきた原稿が壊れる。

**文字数は親文字だけを数える。** ルビは読みであって本文ではない。

## 読む側

| 機能 | 中身 |
|------|------|
| 探す | 題名・作者・キーワード・除外語・ジャンル・タグ・気分 |
| 一覧の形 | 文字だけ／本の形（表紙が並ぶ棚） |
| ランキング | 期間・ジャンル・種別で絞る |
| おすすめ | 読まれた数ではなく割合で選ぶ |
| 読む | 縦書き・横書き・字の大きさ・書体・読み上げ |
| 全画面で読む | 携帯のみ。左右を触って頁を送る |
| 反応 | いいね・保存・感想・引用コメント・発掘 |

### ランキングの点

```
評価（星）    × 1
いいね        × 2
保存          × 2
続けて読んだ   × 1.3     同じ人が 2 話以上読んだ数
読まれた数     × 0.2
```

保存は「あとで読む」の印で、読んだ証しではない。
続けて読んだほうが、面白かったことを強く表す。

### おすすめの点

読了率・保存率・いいね率・感想率などの **割合** で選ぶ。
数ではないので、読まれた数が少なくても上に来られる。
「まだ知られていない作品を掘り出す」という狙いに合わせている。

## AI の扱い

**本文と表紙の生成は行わない。** 指示文そのものが無いので、設定で入れることもできない
（`src/lib/ai/prompts.ts`）。

AI が使われるのは、資料候補を拾う所と図案を作る所だけ。

作品ごとに、AI をどこまで使ったかを作者が申告する。

```
none     使っていない
assist   下調べなどに使った
full     本文を AI が書いた
```

読者は、マイページで「AI が書いた作品を出さない」を選べる。
そのとき外れるのは `full` だけで、表紙を AI で作っただけの作品は残る。

表紙と挿絵には、AI で作ったことを示す印を出せる。

### 決めごと

- `app/` にはルートファイルだけ置く。UI は `components/` へ
- ファイル名は kebab-case、部品名は PascalCase
- import は `@/` だけ使う。相対 import は使わない
- 環境変数は `process.env` を直接見ず、`config/` を通す
- **データの読み書きは必ず `getRepository()` 経由。** 画面から Supabase を直接触らない

## 気をつける所

**PDF の読み込み** は `pdfjs-dist` を使う。PDF は文字の位置しか持たないため、
改行や段落が原稿どおりに戻らないことがある。取り込み後の手直しを前提にする。

**PDF の書き出し** は生成ライブラリを使わず、印刷用の頁を開いてブラウザの
「PDF として保存」に渡す。日本語の埋め込みと縦書きの両方を標準機能で扱えるため。
ポップアップの許可が要る。

**ホームの本棚** は `public/home/home.js` にある素の JavaScript。
本の大きさと位置が同じ計算から出ているので、片方だけ変えると本が散らばる。

**縦書きの中に横書きの物を置くとき** は `writingMode` を戻す。
戻さないと、その入れ物まで縦に伸びる。

**話を公開すると、作品も自動で公開になる。**
作者は「話を公開した＝読める」と思っているが、
作品の公開設定が別にあり、そちらが下書きのままだと誰にも読まれない。
逆はしない。作品を下書きに戻しても、話は触らない。

## バックアップ

作品一覧の「バックアップ」から、すべての作品・原稿・資料・設定を
1 つの JSON にまとめて取り出せる。7 日以上あくと画面で知らせる。

戻し方は 2 通り。

- **足す** … いまのものを残し、バックアップにしか無いものだけ入れる
- **置き換える** … いまのものを消してから入れる

形式に版番号が入っていて、新しい形式を古いアプリで開こうとすると止まる。
