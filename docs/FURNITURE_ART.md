# 家具の絵の作り方

> ドット絵を描く／発注するときの決まり。
> ここを揃えないと、部屋の中で角度や大きさがばらついて見えます。

---

## 1. マス目と絵の細かさは別

**1 マス = 16px。**
机なら 6 マス × 4 マス（96px × 64px）という数え方になります。

ただしこれは「どこに置くか」を決める単位で、
絵の細かさとは関係ありません。

6 マスの家具に 600px で描いた絵を入れても構いません。
表示するときに縮めます。

- 粗いドット絵にしたい → そのまま（`pixelated: true`）
- きめの細かい絵 → `pixelated: false` を付けると滑らかに縮まります

---

## 2. 足元と絵の大きさ

家具は 2 つの大きさを持ちます。

| | 何を決めるか |
|---|---|
| `cols` / `rows` | 床で占める広さ（足元）。ここに他の家具は置けない |
| `artCols` / `artRows` | 絵の大きさ。省くと足元と同じ |

**絵は足元より大きくて構いません。** 上へはみ出します。

```
   ┌─────┐
   │     │  ← 絵（artRows: 3）
   │ 本棚 │
   ├─────┤
   │▓▓▓▓▓│  ← 足元（rows: 1）ここだけ占有
   └─────┘
```

背の高いものを足元の枠に押し込めると、
本棚もベッドも同じ高さの板に見えてしまいます。

絵は**足元の下端に合わせて**置かれ、横は中央に揃います。

---

## 3. 揃えること

**角度** — 床は真上から、家具は斜め前（およそ 45 度）から。
すべての家具で同じ角度にしてください。
真上から描くと、本棚が長方形、椅子が丸になって何か分かりません。

**光の向き** — 光は左上から。影は右下へ落とします。
家具ごとに影の向きが違うと、部屋が壊れて見えます。

**足元の影** — 必ず入れてください。無いと床から浮いて見えます。

---

## 4. 向きごとの絵

家具を回すとき、**1 枚の絵を回すだけでは形が崩れます。**
机の脚や椅子の背もたれが、あり得ない向きになります。

そこで、向きごとに 4 枚描いてください。

| 向き | 何を描くか |
|---|---|
| `down` | 正面図。手前を向いている状態 |
| `up` | 背面図。奥を向いている状態 |
| `right` | 右側面図 |
| `left` | 右側面図を左右に裏返したもの |

カタログにはこう書きます。

```ts
sprite: {
    down:  "/furniture/desk-down.png",
    up:    "/furniture/desk-up.png",
    left:  "/furniture/desk-left.png",
    right: "/furniture/desk-right.png",
},
```

**1 枚だけでも動きます。** その場合は回して使うので、
まず 1 枚で置いてみて、崩れる家具から描き足すのが早いです。

回さないもの（丸テーブル・鉢植えなど）は 1 枚で足ります。

### 4 枚を渡すときの決まり

**4 面とも同じ縮尺で描いてください。**
1 枚だけ大きいと、回したとき家具の大きさが変わって見えます。

正面図の幅を「足元の横マス数」に合わせるのが目安です。
椅子なら 4 マス（64px）。側面図は多少はみ出して構いません。

**縦横は入れ替えません。**
側面図は縦長に描かれているので、そのまま置きます。
1 枚しか無いときだけ、回すのに合わせて縦横を入れ替えます。

---

## 5. 入れ方

1. `public/furniture/` に置く（例：`public/furniture/desk.png`）
2. `src/lib/room/furniture-catalog.ts` の該当行に足す

```ts
{
    id: "bookshelf",
    label: "本棚",
    category: "storage",
    layer: "floor",
    cols: 2, rows: 1,        // 足元
    artRows: 3,              // 絵は上へ 3 マス
    rotatable: true,
    shape: "shelf",          // 絵が無いときの図形。残しておく
    tone: "#7a5c3d",
    sprite: "/furniture/bookshelf.png",
    pixelated: true,
}
```

`sprite` があればそちらが使われ、無ければ図形が出ます。
**1 つずつ差し替えられます。** 全部揃うまで待つ必要はありません。

---

## 6. 層

| 層 | 何を置くか | 重なり |
|---|---|---|
| `floor` | 机・椅子・棚・ベッド | 人と混ざる |
| `wall` | 窓・額縁・時計 | 人より奥 |
| `top` | カップ・本・小さな鉢 | 人より手前 |

層が違うものは重ねて置けます。
机の上にカップを置けるのはこのためです。
