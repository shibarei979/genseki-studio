============================================================
原石航路 Studio — はじめかた
============================================================

■ 1. 展開する

  この zip を好きな場所に展開します。
  「genseki-studio」というフォルダができます。


■ 2. 必要なものを入れる

  そのフォルダで、ターミナル（VS Code なら Ctrl+@）を開いて：

    npm install

  初回は数分かかります。


■ 3. 動かす

    npm run dev

  ブラウザで http://localhost:3000 を開きます。
  これだけで全部の機能が使えます。


============================================================
AI補助を本物にする（任意）
============================================================

  鍵を入れなくても動きます。その場合、本文は外部へ送られず、
  端末の中だけで動く簡易版が使われます。

  本物のモデルを使うなら：

  1) platform.openai.com にログイン
  2) Billing でクレジットカードを登録（無料枠はありません）
  3) Settings → API keys → Create new API key
  4) このフォルダ（package.json と同じ場所）に
     「.env.local」というファイルを作り、1行だけ書く

       OPENAI_API_KEY=sk-proj-（コピーした鍵）

  5) npm run dev を実行し直す

  資料ページの左下に「モデルに接続中」と出れば成功です。

  ※ メモ帳で作る場合、保存時にファイル名を
    "​.env.local" とダブルクォートで囲んでください。
    囲まないと .env.local.txt になってしまいます。


============================================================
Supabase について
============================================================

  supabase/migrations/002_studio_schema.sql は用意してありますが、
  まだ実行しないでください。

  実行しても、アプリ側が読み書きするコードをまだ書いていないので
  何も変わりません。次の2つができてから実行します。

    ・supabase-repository.ts（保存先の差し替え）
    ・ログイン機能（誰のデータか決めるため）

  いまの保存先はブラウザの中だけです。
  大事な作品は、マイページの設定からバックアップを取ってください。


============================================================
困ったとき
============================================================

  画面が真っ白になる、古い表示のままになる：

    .next フォルダを削除して、npm run dev をやり直す

  資料の画面でエラーが出る：

    マイページ → 設定 → データ からバックアップを取ったうえで、
    ブラウザの開発者ツール（F12）→ Application →
    Local Storage の中身を消すと直ることがあります
