============================================================
原石航路 — 旧サイトの転送について
============================================================

この vercel.json は、旧サイト（gensekikoro-jp）の
リポジトリの直下に置くもの。

置くと、旧住所のどの頁に来た人も、
今のサイト（genseki-studio-bay）の同じ場所へ送られる。

  例）旧 /novel/123  →  新 /novel/123

permanent: true は「引っ越しました」の合図。
検索エンジンはこれを見て、
検索結果を新しい住所に置き換える。

------------------------------------------------------------
入れかた
------------------------------------------------------------

1. Vercel で旧プロジェクトを Resume（再開）する
   止めたままだと転送も動かない。
   Settings → 一時停止の欄、または Deployments から再開。

2. 旧リポジトリの直下（package.json と同じ場所）に
   この vercel.json を置く

3. 送る

   git add .
   git commit -m "chore: redirect old site to new domain"
   git push

4. デプロイが終わったら、旧住所をブラウザで開く。
   今のサイトへ飛べば成功。

------------------------------------------------------------
注意
------------------------------------------------------------

・旧サイトの中身は動かなくなる（全部転送される）。
  参照用に中身を見たいときは、
  手元の GENSEKIKORO のファイルを見ること。

・独自ドメイン（gensekikoro.jp）を今のサイトに繋いだら、
  この転送先も新しい住所に書き換えること。
  書き換えないと、旧サイトから古い住所へ送り続ける。
